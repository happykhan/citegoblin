# Third-party components

- **citeproc-js 2.4.63**: installed through the pinned npm lockfile. Distributed under upstream AGPL-3.0 or CPAL-1.0 terms; consult its package licence files before redistribution or deployment. Runs as a separate Node.js process.
- **Elsevier Harvard**, **NLM citation-sequence**, **IEEE**, **APA**, **Nature**, **Chicago author–date** and **MLA** CSL styles: Citation Style Language styles repository, https://github.com/citation-style-language/styles. Licence links, attribution and source metadata are retained within each `.csl` file. These are not covered by the project's MIT licence.
- **en-GB and en-US CSL locales**: https://github.com/citation-style-language/locales. See the retained attribution and licence declaration within the locale XML files. New styles are pinned to CSL repository commit `7fa488bd2f765eb161e93c7963838ee2c9c17fe5`.

No manuscript or user document data is bundled.
